## О проекте

Проект реализован на **React + TypeScript** с использованием:
- глобального состояния через **Redux Toolkit** и **react-redux**;
- маршрутизации через **react-router-dom**;
- HTTP-запросов через **axios**;
- локального backend-сервиса на Node.js (`server/index.ts`).

Приложение демонстрирует типовой production-подход для учебного/демо-проекта: строгая типизация, разделение по слоям, обработка загрузки и ошибок, защищенные маршруты.

## Технологии

| Категория | Используется |
|---|---|
| Frontend | React 19, TypeScript |
| State management | Redux Toolkit, react-redux |
| Routing | react-router-dom |
| API client | axios |
| Build | react-scripts |
| Backend (local) | Node.js HTTP server (`server/index.ts`) |

## Структура проекта

```text
src/
  api/            # axios instance + API-методы
  components/     # переиспользуемые компоненты
  data/           # локальные типы/данные каталога
  hoc/            # AuthWrapper, CommonWrapper
  hooks/          # кастомные React-хуки
  pages/          # страницы приложения
  store/          # Redux store и slices
  theme/          # тема/провайдер оформления
  ui/             # базовые UI-элементы
  utils/          # утилитарные функции
```

## Функциональность

- Регистрация и авторизация пользователя
- Личный кабинет и страница данных после авторизации
- Каталог домашнего персонала
- Избранное, корзина, заказы
- Глобальная индикация загрузки и отображение ошибок
- Защита приватных маршрутов
- Страница 404 с возвратом в корень маршрутов

## API и HTTP-методы

В проекте реализованы все требуемые методы через `axios`:

- `GET`: получение каталога, профиля, dashboard, заказов
- `POST`: логин, регистрация, создание заказа
- `PUT`: обновление профиля
- `PATCH`: обновление интересов пользователя
- `DELETE`: удаление заказа

Базовый URL задается в `src/api/axiosInstance.ts`:
- `REACT_APP_API_URL` (если передан)
- либо `http://localhost:4000/api` по умолчанию

## Быстрый старт

### 1) Установка зависимостей

```bash
npm install
```

### 2) Запуск backend

```bash
npm run server
```

### 3) Запуск frontend

```bash
npm start
```

Frontend: `http://localhost:3000`  
Backend: `http://localhost:4000`
