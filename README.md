# House Staff
Задание по фронту 3 курс 2 семестр.
Современное веб-приложение для сервиса домашнего персонала: каталог специалистов, авторизация, личный кабинет и управление заявками.

## Стек

- Next.js App Router
- TypeScript strict mode
- FSD: `app`, `features`, `entities`, `shared`, `widgets`
- MobX root store
- Axios API client

## Команды

```bash
npm run dev
npm run build
npm run start
npm run test
npm run server
```

Для клиентских запросов нужен локальный API:

```bash
npm run server
```
