# Текст Для Защиты

Проект `Home Staff` реализован как многостраничное веб-приложение на React и TypeScript с локальным backend-сервисом. На клиентской части используется `react-router-dom` для маршрутизации, `axios` для работы с API, `react-redux` и `@reduxjs/toolkit` для управления состоянием.

Архитектура проекта разделена по смыслу:
- `src/pages` содержит отдельные страницы приложения;
- `src/components` содержит переиспользуемые компоненты;
- `src/ui` содержит кастомную кнопку;
- `src/utils` содержит утилиты форматирования;
- `src/store` содержит Redux store и slices;
- `src/api` содержит слой запросов к серверу.

В приложении реализованы обязательные страницы:
- лендинг;
- вход;
- регистрация;
- личный кабинет;
- страница после авторизации;
- дополнительные страницы: каталог, персонал, корзина, 401 и 404.

Для контроля доступа и состояния используются два обёрточных компонента:
- `AuthWrapper` ограничивает доступ к закрытым страницам и показывает 401-страницу;
- `CommonWrapper` показывает глобальный loader и модальное окно ошибки.

На уровне состояния используются обязательные slices:
- `userSlice` хранит данные пользователя, токен и авторизацию;
- `settingsSlice` управляет загрузкой и ошибками;
- дополнительные slices: `catalogSlice`, `cartSlice`, `favoritesSlice`, `ordersSlice`.

Также выполнено требование по взаимодействию между slices: `favoritesSlice` использует actions других slices через `extraReducers`.

На уровне API реализованы все требуемые HTTP-методы:
- `GET` для получения каталога, dashboard и списка заявок;
- `POST` для входа, регистрации и отправки заявки;
- `PUT` для обновления профиля;
- `PATCH` для обновления интересов пользователя;
- `DELETE` для удаления заявки.

Backend хранит данные пользователей и заявок в локальном JSON-файле `server/data.json`, поэтому регистрация и вход сохраняются между перезапусками сервера.

Для UI/UX все действия пользователя подписаны: у кнопок есть названия, а у кастомной кнопки поддерживается tooltip. Также реализованы уведомления об ошибках и загрузка данных.

Проект успешно собирается через `npm run build`, а маршрутизация включает обработку 404 и 401 состояний.
